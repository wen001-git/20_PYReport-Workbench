## Node/npm 限制与 Vue/Vite 状态

- 此前访问 npm 官方源出现 `UNABLE_TO_GET_ISSUER_CERT_LOCALLY`；截图记录临时启用 Windows 系统证书信任后，返回 HTTP 403 Forbidden。
- 这些结果表明依赖获取仍有证书配置或访问方面的阻碍；403 的具体来源与解决方式不能仅凭截图确定。
- Vue 3/Vite 尚未完成实际依赖安装、开发服务启动或生产构建验证，不列为已验证的开发能力。
- 当前前端选用原生 JavaScript；若以后重新评估 Vue/Vite，先按公司允许的包源或离线安装方式验证完整开发流程。
